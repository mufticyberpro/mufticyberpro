# SOC & Microsoft Security Labs

Hands-on security operations labs focused on threat detection, security investigations, identity security, and incident response using Microsoft's security ecosystem.

## Labs

| Lab | Focus | Status |
|---|---|---|
| Microsoft Sentinel — Authentication Investigation | Sign-in logs, KQL and suspicious authentication activity | In progress |
| Microsoft Defender XDR — Entra Sign-In Investigation | Authentication events and Advanced Hunting | Planned |
| Microsoft Defender XDR — Incident Investigation | Incident investigation and evidence analysis | Planned |
| Microsoft Sentinel — Detection & Investigation | Detection rules and investigation workflows | Planned |
| Microsoft Entra ID — Identity Investigation | Identity activity, MFA and authentication failures | Planned |
| PowerShell — Security Investigation Scripts | Security triage and investigation automation | Planned |

## Lab Documentation

Each completed lab will include:

- Objective and investigation scenario
- Lab environment and prerequisites
- Step-by-step procedure
- Commands and queries used
- Screenshots and supporting evidence
- Findings, analysis and recommendations
- Lessons learned

## Tools & Technologies

Microsoft Sentinel · Microsoft Defender XDR · Microsoft Entra ID · Kusto Query Language (KQL) · PowerShell

*Practical work and findings will be documented as each lab is completed.*
