# Digital Forensics & DFIR Labs

Practical digital forensic investigations focused on Windows artefacts, memory analysis, activity reconstruction, evidence examination, and incident response.

## Labs

| Lab | Focus | Status |
|---|---|---|
| Windows Digital Forensics Investigation | Event Logs, Registry, Prefetch, Amcache and user activity | Planned |
| Memory Forensics — Volatility | Process analysis, network connections and memory artefacts | Planned |
| Timeline Analysis | Reconstructing activity from multiple forensic artefacts | Planned |
| Autopsy / FTK Forensic Examination | Disk imaging, file examination and evidence analysis | Planned |

## Lab Documentation

Each completed lab will include:

- Investigation objective and scope
- Evidence sources and lab environment
- Tools and examination procedure
- Screenshots and forensic artefacts
- Analysis and findings
- Evidence handling and limitations
- Conclusion and lessons learned

## Tools & Technologies

Autopsy · FTK Imager · Volatility · Windows Event Logs · Registry analysis · Digital forensic timelines

*Only investigations actually performed will be documented as completed, with supporting evidence where appropriate.*
